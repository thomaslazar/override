## Review Focus

1. **App closed in the middle of a cascade:** reload must show the fully resolved board with the move spent, never a half-resolved board or a refunded move. Pinned in Task 9 (save right after `move`, before animating) and by the steps-replay test in Task 3.
2. **Animation and state drift apart:** the UI animates `steps`, but after the last step the board on screen must equal `S`. Pinned by the steps-replay test in Task 3 (replaying steps on an id grid reproduces `S.grid`) and the UI's resync after every move in Task 9.
3. **A save from an older or corrupted version:** `override-v1` holding garbage, a wrong `v`, wrong array lengths or a missing goal must not crash; the level restarts fresh (integer `level` kept) or level 1. Pinned by `validSave` tests in Task 4 and `load()` in Task 10.
4. **Taps during animation or right after a sheet closes:** must never start a second move or fire a swap on the board. Pinned in Task 9 (`busy` gate and 400 ms grace).
5. **The worker is slow or the requested attempt is not cached:** the UI must show the loading card, stay responsive (menu opens), and start the level when the attempt arrives; a stale reply for another `(level, fails)` must be ignored. Pinned in Task 8 (`want()` keyed by `level:fails`) and Task 9.

## State shape (shared by every task)

```js
// S: a level attempt. Plain data, JSON-safe, saved whole.
{
  v: 1,                 // save version
  level: 1, fails: 0,   // level number (>= 1), failed attempts on it so far
  salt: 0, drop: 0,     // layout salt and difficulty drop chosen by prepare()
  n: 8,                 // board side (7..9)
  k: 5,                 // colours in play (4..6); tile colours are 0..k-1
  types: [3,0,5,1,6],   // glyph/colour slot (0..6) for each colour 0..k-1, seeded per level
  grid: [/* n*n */],    // tile object or null; index i = r * n + c
  enc: [/* n*n */],     // encrypted hits left per cell (0 = none)
  goals: [{ kind: 'tiles', t: 2, need: 20, got: 0 }, { kind: 'crack', need: 8, got: 0 }, { kind: 'firewall', need: 3, got: 0 }],
  moves: 22, limit: 22, need: 17,   // moves left, starting limit, bot's median need
  seed: 123456,         // refill and shuffle seed (from level, fails, salt)
  spawns: 0, shuffles: 0, ids: 0,   // counters: tiles spawned, reshuffles, next tile id
  nice: true,           // helpful refill on (player) or off (bot)
}
// tile: { id: 17, t: 2, s: null | 'h' | 'v' | 'b' | 'z', lock: false }
// zero-day: t === -1, s === 'z'. Worms and bombs keep their colour t.
```

## Steps returned by `move(S, a, b)` (the UI contract)

`move` returns `{ ok: boolean, steps: Step[] }`. Steps in order:

```js
{ k: 'swap', a, b }                         // tiles at a and b exchanged
{ k: 'back', a, b }                         // swap undone (only with ok: false)
{ k: 'combo', i, kind }                     // two specials swapped; kind 'ww'|'bw'|'bb'|'zw'|'zb'|'zz'; i = centre
{ k: 'convert', cells: [{ i, s }] }         // zero-day + special: tiles became specials
{ k: 'wave', fired: [{ i, s }], cleared: [{ i, id }], cracked: [{ i, hp }], unlocked: [i], created: [{ i, tile }] }
{ k: 'fall', moves: [{ id, from, to }], spawns: [{ i, tile }] }   // one gravity pass
{ k: 'shuffle', tiles: [{ i, id, t }] }     // reshuffle: tile id now at i, with colour t
```

```js
import { tile } from '../src/core.js';

// Builds a state from rows of space-separated tokens:
// 'A'..'F' colour 0..5, suffix 'h' | 'v' | 'b' makes that special, suffix '!' locks it (firewall),
// 'Z' zero-day, '#1'..'#3' encrypted cell with that many hits, '.' empty cell.
export function mk(rows, o = {}){
  const n = rows.length;
  const S = { v: 1, level: 1, fails: 0, salt: 0, drop: 0, n, k: o.k ?? 6, types: [0, 1, 2, 3, 4, 5, 6],
    grid: Array(n * n).fill(null), enc: Array(n * n).fill(0),
    goals: o.goals ?? [{ kind: 'tiles', t: 0, need: 999, got: 0 }],
    moves: o.moves ?? 30, limit: o.limit ?? 30, need: 0, seed: o.seed ?? 1, spawns: 0, shuffles: 0, ids: 0, nice: o.nice ?? false };
  rows.forEach((row, r) => row.trim().split(/\s+/).forEach((tok, c) => {
    const i = r * n + c;
    if (tok === '.') return;
    if (tok[0] === '#') { S.enc[i] = +tok.slice(1) || 1; return }
    if (tok === 'Z') { S.grid[i] = tile(S, -1, 'z'); return }
    const m = tok.match(/^([A-F])([hvb])?(!)?$/);
    if (!m) throw new Error('bad token ' + tok);
    const x = tile(S, m[1].charCodeAt(0) - 65, m[2] || null);
    if (m[3]) x.lock = true;
    S.grid[i] = x;
  }));
  return S;
}
export const ids = S => S.grid.map(x => x ? x.id : null);
```

```js
// Override rules. Pure: no DOM, no storage. Everything random is seeded.

/* ---------- random ---------- */
export function mulberry32(a){
  return () => { a |= 0; a = a + 0x6D2B79F5 | 0; let t = Math.imul(a ^ a >>> 15, 1 | a); t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t; return ((t ^ t >>> 14) >>> 0) / 4294967296 };
}
export function hash(...xs){
  let h = 2166136261;
  for (const x of xs) { h ^= x | 0; h = Math.imul(h, 16777619); h ^= h >>> 13 }
  return h >>> 0;
}
export const rngFor = (...xs) => mulberry32(hash(...xs));

/* ---------- board helpers ---------- */
export const TYPES = 7;   // glyph and colour slots; a level uses k of them
const range = (a, b) => Array.from({ length: b - a }, (_, k) => a + k);
export const rc = (S, i) => [Math.floor(i / S.n), i % S.n];
export const at = (S, r, c) => r >= 0 && c >= 0 && r < S.n && c < S.n ? r * S.n + c : -1;
export const nbrs = (S, i) => { const [r, c] = rc(S, i); return [at(S, r - 1, c), at(S, r + 1, c), at(S, r, c - 1), at(S, r, c + 1)].filter(j => j >= 0) };
export const tile = (S, t, s = null) => ({ id: S.ids++, t, s, lock: false });
export const movable = (S, i) => { const x = S.grid[i]; return !!x && !x.lock };
// The colour a cell matches with, or -1 (empty, encrypted, outside, zero-day).
export const colourAt = (S, r, c) => { const i = at(S, r, c), x = i < 0 ? null : S.grid[i]; return x && x.s !== 'z' ? x.t : -1 };

/* ---------- matching ---------- */
export function findGroups(S){
  const { n } = S, runs = [];
  for (let r = 0; r < n; r++) for (let c = 0; c < n;) {
    const t = colourAt(S, r, c); let e = c + 1;
    while (t >= 0 && e < n && colourAt(S, r, e) === t) e++;
    if (t >= 0 && e - c >= 3) runs.push({ h: true, cells: range(c, e).map(x => r * n + x) });
    c = e;
  }
  for (let c = 0; c < n; c++) for (let r = 0; r < n;) {
    const t = colourAt(S, r, c); let e = r + 1;
    while (t >= 0 && e < n && colourAt(S, e, c) === t) e++;
    if (t >= 0 && e - r >= 3) runs.push({ h: false, cells: range(r, e).map(x => x * n + c) });
    r = e;
  }
  // runs that share a cell form one group
  const owner = new Map(), groups = [];
  for (const run of runs) {
    let g = null;
    for (const i of run.cells) {
      const o = owner.get(i);
      if (!o || o === g) continue;
      if (!g) { g = o; continue }
      for (const x of o.runs) g.runs.push(x);
      for (const j of o.cells) { g.cells.add(j); owner.set(j, g) }
      o.dead = true;
    }
    if (!g) groups.push(g = { runs: [], cells: new Set() });
    g.runs.push(run);
    for (const i of run.cells) { g.cells.add(i); owner.set(i, g) }
  }
  return groups.filter(g => !g.dead);
}
// The special a group makes. `swipe` ('h' | 'v') is set when the group came from the player's swap.
export function specialOf(g, swipe){
  const max = Math.max(...g.runs.map(x => x.cells.length));
  if (max >= 5) return 'z';
  if (g.runs.some(x => x.h) && g.runs.some(x => !x.h)) return 'b';
  if (max === 4) return swipe || (g.runs.find(x => x.cells.length === 4).h ? 'h' : 'v');
  return null;
}
// Where the special goes: a swapped cell in the group, else the crossing (bomb), else the middle of the longest run.
export function spotOf(g, s, prefer = []){
  for (const i of prefer) if (g.cells.has(i)) return i;
  if (s === 'b') {
    const hs = new Set(g.runs.filter(x => x.h).flatMap(x => x.cells));
    for (const x of g.runs) if (!x.h) for (const i of x.cells) if (hs.has(i)) return i;
  }
  const L = g.runs.reduce((a, b) => b.cells.length > a.cells.length ? b : a);
  return L.cells[L.cells.length >> 1];
}
export function lineAt(S, i){
  const [r, c] = rc(S, i), t = colourAt(S, r, c);
  if (t < 0) return false;
  let h = 1, v = 1;
  for (let k = c - 1; colourAt(S, r, k) === t; k--) h++;
  for (let k = c + 1; colourAt(S, r, k) === t; k++) h++;
  for (let k = r - 1; colourAt(S, k, c) === t; k--) v++;
  for (let k = r + 1; colourAt(S, k, c) === t; k++) v++;
  return h >= 3 || v >= 3;
}
export function swapLegal(S, a, b){
  if (!movable(S, a) || !movable(S, b)) return false;
  const A = S.grid[a], B = S.grid[b];
  if (A.s || B.s) return true;
  S.grid[a] = B; S.grid[b] = A;
  const ok = lineAt(S, a) || lineAt(S, b);
  S.grid[a] = A; S.grid[b] = B;
  return ok;
}
export function validMoves(S){
  const out = [];
  for (let i = 0; i < S.n * S.n; i++) {
    const [r, c] = rc(S, i);
    for (const j of [at(S, r, c + 1), at(S, r + 1, c)]) if (j >= 0 && swapLegal(S, i, j)) out.push([i, j]);
  }
  return out;
}
export function hasMove(S){
  for (let i = 0; i < S.n * S.n; i++) {
    const [r, c] = rc(S, i);
    for (const j of [at(S, r, c + 1), at(S, r + 1, c)]) if (j >= 0 && swapLegal(S, i, j)) return true;
  }
  return false;
}
// Fills every free cell without a match, retrying until a move exists. Encrypted cells stay empty.
export function fillBoard(S, rnd){
  do {
    for (let i = 0; i < S.n * S.n; i++) {
      S.grid[i] = null;
      if (S.enc[i]) continue;
      const [r, c] = rc(S, i);
      let t;
      do t = Math.floor(rnd() * S.k);
      while ((colourAt(S, r, c - 1) === t && colourAt(S, r, c - 2) === t) || (colourAt(S, r - 1, c) === t && colourAt(S, r - 2, c) === t));
      S.grid[i] = tile(S, t);
    }
  } while (!hasMove(S));
}
```

```js
/* ---------- refill ---------- */
// Helpful refill (spec, Fairness): weights only ever add to 1, never against the player.
export const REFILL = { A: 1.5, B: 0.5, M: 2 };
// 0 while goal progress keeps pace with moves used, up to 1 when far behind. 0 without a limit (bot).
export function pressure(S){
  if (!S.limit) return 0;
  let need = 0, got = 0;
  for (const g of S.goals) { need += g.need; got += Math.min(g.got, g.need) }
  const used = (S.limit - S.moves) / S.limit, progress = need ? got / need : 1;
  return Math.max(0, Math.min(1, (used - progress) * 2));
}
// Colour t at cell i makes a near pair (same colour next to it, or one cell further in a line),
// but not a direct match: free cascades get no help.
export function setsUp(S, i, t){
  const old = S.grid[i];
  S.grid[i] = { t, s: null };
  const [r, c] = rc(S, i);
  let ok = false;
  if (!lineAt(S, i)) for (const [dr, dc] of [[0, 1], [1, 0], [0, -1], [-1, 0]])
    if (colourAt(S, r + dr, c + dc) === t || colourAt(S, r + 2 * dr, c + 2 * dc) === t) { ok = true; break }
  S.grid[i] = old;
  return ok;
}
export function refillWeights(S, i){
  const w = Array(S.k).fill(1);
  if (!S.nice) return w;
  const p = pressure(S);
  for (let t = 0; t < S.k; t++) {
    if (setsUp(S, i, t)) w[t] += REFILL.A + REFILL.M * p;
    if (S.goals.some(g => g.kind === 'tiles' && g.t === t && g.got < g.need)) w[t] += REFILL.B;
  }
  return w;
}
export function spawnColour(S, i){
  const w = refillWeights(S, i);
  let x = rngFor(S.seed, 7, S.spawns++)() * w.reduce((a, b) => a + b, 0);
  for (let t = 0; t < w.length; t++) if ((x -= w[t]) < 0) return t;
  return w.length - 1;
}
```

```js
function commonColour(S){
  const m = Array(S.k).fill(0);
  for (const x of S.grid) if (x && x.s !== 'z') m[x.t]++;
  return m.indexOf(Math.max(...m));

function square(S, i, d){
  const [r, c] = rc(S, i), out = [];
  for (let a = r - d; a <= r + d; a++) for (let b = c - d; b <= c + d; b++) { const j = at(S, a, b); if (j >= 0) out.push(j) }
  return out;

// Cells a fired special clears.
function area(S, i, x){
  const [r, c] = rc(S, i), n = S.n;
  if (x.s === 'h') return range(0, n).map(k => r * n + k);
  if (x.s === 'v') return range(0, n).map(k => k * n + c);
  if (x.s === 'b') return square(S, i, 1);
  const t = x.target ?? commonColour(S);   // zero-day: the swapped tile's colour, else the most common
  return range(0, n * n).filter(j => S.grid[j] && S.grid[j].s !== 'z' && S.grid[j].t === t);

function bump(S, kind, t){ for (const g of S.goals) if (g.kind === kind && (kind !== 'tiles' || g.t === t)) g.got++ }
// One wave: fire specials in `cells` (chains), hit blockers, clear tiles, then place new specials.
// `matched` holds cells cleared by matching (they crack encrypted neighbours); `fired` holds ids that must not fire.
function wave(S, cells, matched, creates, fired = new Set()){
  const step = { k: 'wave', fired: [], cleared: [], cracked: [], unlocked: [], created: [] };
  const queue = [...cells];
  while (queue.length) {
    const i = queue.pop(), x = S.grid[i];
    if (!x || !x.s || fired.has(x.id)) continue;
    fired.add(x.id); step.fired.push({ i, s: x.s });
    for (const j of area(S, i, x)) if (!cells.has(j)) { cells.add(j); queue.push(j) }
  }
  const hit = new Set();
  for (const i of cells) if (S.enc[i]) hit.add(i);
  for (const i of matched) for (const j of nbrs(S, i)) if (S.enc[j]) hit.add(j);
  for (const i of hit) { S.enc[i]--; step.cracked.push({ i, hp: S.enc[i] }); if (!S.enc[i]) bump(S, 'crack') }
  for (const i of cells) {
    const x = S.grid[i];
    if (!x) continue;
    if (x.lock) { x.lock = false; step.unlocked.push(i); bump(S, 'firewall'); continue }
    if (x.s !== 'z') bump(S, 'tiles', x.t);
    step.cleared.push({ i, id: x.id }); S.grid[i] = null;
  }
  for (const c of creates) { const x = tile(S, c.t, c.s); S.grid[c.i] = x; step.created.push({ i: c.i, tile: { ...x } }) }
  return step;
}

// A cell is fed when nothing fixed (encrypted cell, firewalled tile) is above it in its column.
function fed(S, i){
  const [r, c] = rc(S, i);
  for (let k = r - 1; k >= 0; k--) { const j = k * S.n + c; if (S.enc[j] || S.grid[j]?.lock) return false }
  return true;
}
const occupied = (S, i) => S.grid[i] || S.enc[i] ? 1 : 0;
function shift(S, from, to, step){ const x = S.grid[from]; S.grid[to] = x; S.grid[from] = null; step.moves.push({ id: x.id, from, to }) }
// Passes until stable: straight down, spawn in row 0, diagonal fill for unfed cells. Roofed pockets stay empty.
function gravity(S, steps){
  const n = S.n;
  for (;;) {
    const step = { k: 'fall', moves: [], spawns: [] };
    for (let r = n - 1; r >= 0; r--) for (let c = 0; c < n; c++) {
      const i = r * n + c;
      if (S.grid[i] || S.enc[i]) continue;
      if (r === 0) { const x = tile(S, spawnColour(S, i)); S.grid[i] = x; step.spawns.push({ i, tile: { ...x } }); continue }
      if (movable(S, i - n)) { shift(S, i - n, i, step); continue }
      if (fed(S, i)) continue;
      // prefer a tile that cannot fall straight itself
      const ds = [c - 1, c + 1].filter(cc => cc >= 0 && cc < n && movable(S, (r - 1) * n + cc))
        .sort((a, b) => occupied(S, r * n + b) - occupied(S, r * n + a));
      if (ds.length) shift(S, (r - 1) * n + ds[0], i, step);
    }
    if (!step.moves.length && !step.spawns.length) return;
    steps.push(step);
  }
}

function cascade(S, steps, prefer = [], swipe = null){

// A swap with at least one special. A is the dragged tile (now at pa), B the other (now at pb).
function combo(S, A, pa, B, pb, steps){

  if (!A.s || !B.s) {

    else if (z) {

      for (let i = 0; i < n * n; i++) {

        if (!y || y.s === 'z' || y.t !== o.t) continue;
        if (!y.s) { y.s = o.s === 'b' ? 'b' : rnd() < .5 ? 'h' : 'v'; conv.push({ i, s: y.s }) }
        cells.add(i);
      }
      steps.push({ k: 'combo', i: pa, kind: o.s === 'b' ? 'zb' : 'zw' }, { k: 'convert', cells: conv });

        if (c + d >= 0 && c + d < n) cells.add(k * n + c + d);
      }

  }

// The player drags the tile at `a` onto `b`. Resolves everything; returns the steps for the UI.
export function move(S, a, b){
  const steps = [];
  if (S.moves <= 0 || won(S) || !nextTo(S, a, b) || !movable(S, a) || !movable(S, b)) return { ok: false, steps };
  const A = S.grid[a], B = S.grid[b];
  S.grid[a] = B; S.grid[b] = A;
  steps.push({ k: 'swap', a, b });
  if (A.s || B.s) { S.moves--; combo(S, A, b, B, a, steps); cascade(S, steps) }
  else if (findGroups(S).length) { S.moves--; cascade(S, steps, [b, a], rc(S, a)[0] === rc(S, b)[0] ? 'h' : 'v') }
  else { S.grid[a] = A; S.grid[b] = B; steps.push({ k: 'back', a, b }); return { ok: false, steps } }
  if (!won(S) && S.moves > 0 && !hasMove(S)) reshuffle(S, steps);
  return { ok: true, steps };
}
// Shuffles movable tiles (seeded) until no match and a valid move; after 200 tries also redraws colours.

    spots.forEach((i, m) => S.grid[i] = tiles[m]);
    if (!findGroups(S).length && hasMove(S)) break;
  }
  steps.push({ k: 'shuffle', tiles: spots.map(i => ({ i, id: S.grid[i].id, t: S.grid[i].t })) });
}
```

```js
// Level generation. Pure and seeded: an attempt follows from level, fails, salt and drop.
import { hash, rngFor, fillBoard, hasMove, reshuffle, TYPES } from './core.js';

/* ---------- chapters & difficulty ---------- */
export const CHAPTER = 30;
export const ENC_FROM = 4, FW_FROM = 7;   // first level with encrypted cells, with firewalls
export const chapterOf = level => {
  const n = Math.floor((level - 1) / CHAPTER) + 1, start = (n - 1) * CHAPTER + 1;
  return { n, start, pos: level - start + 1 };
};
export const breather = level => { const { pos } = chapterOf(level); return pos > 1 && pos % 5 === 1 };
// Ramp over the chapter from its base to 0.85, +0.1 on every 5th level, -0.1 on the level after.
export function difficulty(level){
  const { n, pos } = chapterOf(level), base = Math.min(.25, .05 * (n - 1));
  let d = base + (.85 - base) * (pos - 1) / (CHAPTER - 1);
  if (pos % 5 === 0) d += .1;
  if (breather(level)) d -= .1;
  return Math.max(0, Math.min(1, d));
}

/* ---------- parameters ---------- */
// My-call mappings from the spec; tune with tools/sim.mjs and by playtest.
export function paramsFor(level, fails = 0, drop = 0){
  const d = Math.max(0, difficulty(level) - drop), h = hash(level, 1) % 100;
  let k = level <= 3 || d < .25 || breather(level) ? 4 : d > .8 ? 6 : 5;
  if (fails >= 6) k = Math.max(4, k - 1);
  const n = d < .33 ? (h < 40 ? 9 : 8) : d < .66 ? (h < 15 ? 9 : h < 30 ? 7 : 8) : (h < 45 ? 7 : 8);
  const enc = level < ENC_FROM ? 0 : Math.round(n * n * (.05 + .13 * d));
  const hp = 1 + Math.min(2, Math.floor(d * 3));
  const fw = level < FW_FROM ? 0 : Math.round(1 + 4 * d);
  return { d, k, n, enc, hp, fw };
}

/* ---------- attempts ---------- */
// Layout (encrypted cells, firewalls, goals) depends on level, salt and drop only; tiles also on fails.
export function makeAttempt(level, fails = 0, salt = 0, drop = 0){
  const p = paramsFor(level, fails, drop), n = p.n, nn = n * n, lr = rngFor(level, salt, 2);
  const order = Array.from({ length: TYPES }, (_, i) => i), tr = rngFor(level, 4);
  for (let j = TYPES - 1; j > 0; j--) { const m = Math.floor(tr() * (j + 1)); [order[j], order[m]] = [order[m], order[j]] }
  const S = { v: 1, level, fails, salt, drop, n, k: p.k, types: order.slice(0, p.k),
    grid: Array(nn).fill(null), enc: Array(nn).fill(0), goals: [], moves: 0, limit: 0, need: 0,
    seed: hash(level, fails, salt, 1), spawns: 0, shuffles: 0, ids: 0, nice: true };
  // encrypted cells: mirrored pairs from row 2 down, at most n - 2 per row
  for (let placed = 0, guard = 0; placed < p.enc && guard < 500; guard++) {
    const r = 2 + Math.floor(lr() * (n - 2)), c = Math.floor(lr() * Math.ceil(n / 2)), m = n - 1 - c;
    const inRow = S.enc.slice(r * n, r * n + n).filter(Boolean).length, add = m === c ? 1 : 2;
    if (S.enc[r * n + c] || inRow + add > n - 2) continue;
    const hp = 1 + Math.floor(lr() * p.hp);
    S.enc[r * n + c] = S.enc[r * n + m] = hp;
    placed += add;
  }
  // firewall spots come from the layout stream, so they stay on retry
  const fwSpots = [];
  for (let guard = 0; fwSpots.length < p.fw && guard < 500; guard++) {
    const i = n + Math.floor(lr() * (nn - n));
    if (!S.enc[i] && !fwSpots.includes(i)) fwSpots.push(i);
  }
  fillBoard(S, rngFor(level, fails, salt, 3));
  for (const i of fwSpots) S.grid[i].lock = true;
  if (!hasMove(S)) reshuffle(S, []);
  S.shuffles = 0;
  // goals
  const gr = rngFor(level, salt, 5), cracks = S.enc.filter(Boolean).length;
  if (cracks) S.goals.push({ kind: 'crack', need: cracks, got: 0 });
  if (fwSpots.length && gr() < .5) S.goals.push({ kind: 'firewall', need: fwSpots.length, got: 0 });
  if (S.goals.length < 2 || gr() < .5) {
    const need = Math.round((15 + 25 * p.d) * 5 / p.k), t = Math.floor(gr() * p.k);
    if (p.d > .5 && S.goals.length < 2 && gr() < .4) {
      const u = (t + 1 + Math.floor(gr() * (p.k - 1))) % p.k;
      S.goals.push({ kind: 'tiles', t, need: Math.round(need * .6), got: 0 }, { kind: 'tiles', t: u, need: Math.round(need * .6), got: 0 });
    } else S.goals.push({ kind: 'tiles', t, need, got: 0 });
  }
  return S;
}
```

Note: `S.goals` must end with at most 3 entries; with crack + firewall present the two-colour branch is skipped (`S.goals.length < 2`). The retry test needs the firewall spots to stay the same across fails: they come from `lr` (level, salt) only. If `fillBoard` returns a board where a spot holds no tile (it cannot: spots skip encrypted cells), keep the guard anyway.

```js
// Greedy bot over the core API. Pure. Sets each attempt's move limit (spec, Move limit from the bot).
import { move, validMoves, won, hash, rngFor } from './core.js';
import { makeAttempt } from './levels.js';

export const CAP = 80, K = 1.3, C = 2, RUNS = 3, SALTS = 10;
const copy = S => JSON.parse(JSON.stringify(S));
// Goal progress first, then specials on the board, then tiles cleared (new ids).
function value(S){
  let v = won(S) ? 1e6 : 0;
  for (const g of S.goals) v += 1000 * Math.min(g.got, g.need) / g.need;
  for (const x of S.grid) if (x && x.s) v += 15;
  return v + S.ids * .5;
}
// Plays a copy of S with the given refill seed and no limit; returns the moves used, or Infinity at the cap.
// The bot looks one move ahead including that move's refills (a mild advantage K absorbs).
export function solve(S0, seed, nice = false){
  const S = copy(S0);
  S.nice = nice; S.limit = 0; S.moves = CAP; S.seed = hash(S0.seed, seed, 17);
  const rnd = rngFor(seed, 19);
  while (!won(S) && S.moves > 0) {
    const ms = validMoves(S);
    if (!ms.length) return Infinity;
    let best = ms[0], bv = -Infinity;
    for (const [a, b] of ms) for (const [x, y] of [[a, b], [b, a]]) {
      const T = copy(S); move(T, x, y);
      const v = value(T) + rnd() * .01;
      if (v > bv) { bv = v; best = [x, y] }
    }
    move(S, best[0], best[1]);
  }
  return won(S) ? CAP - S.moves : Infinity;
}
export const limitFor = (need, fails) => Math.ceil((need * K + C) * (1 + Math.min(.4, Math.max(0, fails - 3) * .1)));
// Ready-to-play attempt: tries salts, then lowers difficulty in steps of 0.1, until all RUNS bot runs finish.
export function prepare(level, fails = 0){
  let S;
  for (let drop = 0; drop <= 1; drop = Math.round((drop + .1) * 10) / 10) for (let salt = 0; salt < SALTS; salt++) {
    S = makeAttempt(level, fails, salt, drop);
    const r = Array.from({ length: RUNS }, (_, k) => solve(S, k)).sort((a, b) => a - b);
    if (!Number.isFinite(r[RUNS - 1])) continue;
    S.need = r[RUNS >> 1];
    S.limit = S.moves = limitFor(S.need, fails);
    return S;
  }
  S.need = CAP; S.limit = S.moves = limitFor(CAP, fails);   // unreachable in practice; keeps the game going
  return S;
}
```

The bot tries both directions of each swap because direction decides worm orientation and which special fires where.

- [ ] **Step 2: Worker client with stale-reply guard**

```js
/* ---------- attempts (worker) ---------- */
const worker = new Worker(new URL('./worker.js', import.meta.url), { type: 'module' });
const ready = new Map(), waiting = new Map(), asked = new Set();
const keyOf = (level, fails) => `${level}:${fails}`;
worker.onmessage = e => {
  const { level, fails, S } = e.data, k = keyOf(level, fails);
  ready.set(k, S);
  waiting.get(k)?.(S); waiting.delete(k);
};
function ask(level, fails){ const k = keyOf(level, fails); if (!ready.has(k) && !asked.has(k)) { asked.add(k); worker.postMessage({ level, fails }) } }
// Resolves with a fresh copy of the attempt for (level, fails); only the latest want() is delivered.
let wantKey = null;
function want(level, fails){
  const k = keyOf(level, fails); wantKey = k; ask(level, fails);
  return new Promise(res => {
    const give = S => { if (wantKey === k) res(JSON.parse(JSON.stringify(S))) };
    ready.has(k) ? give(ready.get(k)) : waiting.set(k, give);
  });
}
const prefetch = (level, fails) => { ask(level + 1, 0); ask(level, fails + 1) };
```

```js

  for (const s of steps) {
    if (s.k === 'swap' || s.k === 'back') {
      const A = idAt.get(s.a), B = idAt.get(s.b);
      place(sprites.get(A), s.b); place(sprites.get(B), s.a); idAt.set(s.a, B); idAt.set(s.b, A);

    if (s.k === 'convert') { for (const c of s.cells) sprites.get(idAt.get(c.i)).s = c.s; await sleep(450) }
```

```js
// Offline play, latest version when online: network first, cache as fallback.
// Requests skip the browser's HTTP cache (GitHub Pages sends max-age=600) and revalidate
// with the server, so a deploy shows up on the next launch. Offline, or after 3 s, the
// cached copy is used.
const CACHE = 'override-1';   // a new name drops the old cache, see activate; only override- caches, the origin is shared with Kiln and Splice
const SHELL = ['./', 'index.html', 'style.css', 'fonts/barlow-semi-condensed-latin-400.woff2', 'fonts/barlow-semi-condensed-latin-600.woff2',
  'src/core.js', 'src/levels.js', 'src/bot.js', 'src/worker.js', 'src/ui.js', 'manifest.webmanifest',
  'lang/languages.json', 'lang/en.json',
  'icons/icon.svg', 'icons/icon-192.png', 'icons/icon-512.png', 'icons/apple-touch-icon.png'];

self.addEventListener('install', e => {
  e.waitUntil(caches.open(CACHE).then(c => c.addAll(SHELL.map(u => new Request(u, { cache: 'no-cache' })))));
  self.skipWaiting();
});
self.addEventListener('activate', e => e.waitUntil(
  caches.keys().then(ks => Promise.all(ks.filter(k => k.startsWith('override-') && k !== CACHE).map(k => caches.delete(k)))).then(() => self.clients.claim())));
self.addEventListener('fetch', e => {
  const url = new URL(e.request.url);
  if (e.request.method !== 'GET' || url.origin !== location.origin) return;
  const key = url.origin + url.pathname;   // one cache entry per file, whatever the query string
  e.respondWith((async () => {
    const c = await caches.open(CACHE);
    try {
      const opts = { cache: 'no-cache' };
      if (AbortSignal.timeout) opts.signal = AbortSignal.timeout(3000);
      const r = await fetch(e.request.url, opts);   // by URL: navigation requests cannot take options
      if (r.ok) c.put(key, r.clone());
      return r;
    } catch {
      return (await c.match(key)) || Response.error();
    }
  })());
});
```

```markdown
# Override

An ad-free match-3 for phones. You are the crew’s hacker on site: jack your field deck into
the lock, line up three or more, and crack it before the patrol comes back. Levels are
generated endlessly, every level is checked beatable by a bot, and the board never runs
out of moves.

**Play:** https://thomaslazar.github.io/override/ (work in progress)

## Install on your phone

Override is a progressive web app and works offline once loaded.

- **iPhone (Safari):** tap Share, then “Add to Home Screen”.
- **Android (Chrome):** open the menu, then “Add to Home screen” or “Install app”.

## How to play

Swap two neighbouring tiles to line up three or more of one kind. Four in a line makes a
worm that clears a row or column, an L or T makes a logic bomb, five in a line makes a
zero-day that clears a whole colour. Swap a special to set it off, or swap two specials
together for a bigger effect. Meet every goal before the moves run out.

## Fair by design

No ads, no accounts, no tracking, no lives or timers. Progress is saved in your browser.
Refills lean your way when you’re behind, never against you. Fail a level four times and
each retry gives more moves; keep failing and it drops a colour.

## Run locally

No build step and no dependencies. Serve the folder with any static server:

```
python3 -m http.server 8081
```

Then open http://localhost:8081. Opening `index.html` from disk does not work, because
browsers block ES modules on `file://`. `?level=N` starts level N when playing locally.
```
